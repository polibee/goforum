# 36 后台管理界面现代化

> 对应 2026-11-19 后台 UI/UX 审计。保持 Go 模板 + Tailwind + Alpine CSP，不引入 SPA 或前端框架。

## 1. 设计底座

- 新增画布/表面层级：`--gf-canvas`、`--gf-surface`、`--gf-surface-muted`、`--gf-surface-subtle`，并在微信/简约/抖音主题下分别覆盖。
- 卡片改为极细边框 + 轻投影；表格表头使用浅色底、行悬停、统一 13px 正文与 5 号行高。
- 字体栈优先 `Inter var/Inter`，数字统一 `gf-tabular`（`font-variant-numeric: tabular-nums`）。
- 修复 `.brand-dot` 在后台无背景的问题，统一品牌渐变。
- 后台最小字号提升到 10px，移除了 8px/9px 的任意字号。

## 2. 后台外壳

- 侧边栏分组增加线性图标，分组默认展开；支持桌面端 `240px ↔ 76px` 收起，状态保存在 `localStorage`。
- 桌面侧边栏固定在视口内（`sticky top-0 h-screen`），设置等长页面滚动时导航保持可见；导航区域独立滚动。
- 顶栏只保留紧凑面包屑，页面标题下放到内容区，消除双标题。
- 顶栏新增命令面板入口：点击或 `⌘K / Ctrl+K` 打开；`/` 也可在非输入状态下打开。
- 命令面板读取服务端注入的后台导航，支持按当前语言显示页面名，并保留前台主题/用户搜索。
- 移动端保留菜单按钮、搜索图标、主题、语言和账号入口。

## 3. 仪表盘

- 4 张 KPI 卡片全部可点击跳转，展示 7 日环比与 Sparkline。
- 增长图改为纯 SVG 面积/折线图，支持 7 / 14 / 30 天切换，含峰值、网格、日期与点位 Tooltip。
- 待处理卡片在 0 时展示完成态，非 0 时展示举报/审核/申诉明细。
- 「运营动态」展示最新注册与已支付订单；「系统健康」展示数据库、版本、模块/设置数量与维护入口。
- 原「模块状态」大表从仪表盘移除，保留到「系统 → 模块清单」。

## 4. 站点设置

- 取消 224px 二级侧边栏，改为顶部可换行分类标签 + 搜索的一体化 sticky 栏。
- 布尔设置统一为 Toggle Switch，状态文案随开关变化；移除了每行暴露的底层设置键名（保留 label tooltip）。
- 保存条仅在 `dirtyCount > 0` 时出现，显示未保存数量、「放弃」与「保存更改」。
- 修正锚点/滚动偏移，分类跳转不会被 sticky 栏遮挡。
- 修复布尔项快照取到隐藏 `false` 输入导致「改动无法识别」的问题。

## 5. 列表与商业化

- 用户列表：筛选与表格分层收敛，批量操作改为勾选后出现的底部浮动条（已选数量 + 动作 + 执行）。
- 支付渠道由表格改为 2–3 列卡片网格，含模式徽章、状态、配置入口与启停按钮。
- 表格样式全局升级；现有 `gf-table-cards` 移动端卡片模式保留。

## 7. 验证

- `npm run build`、`go test ./...`、`go vet ./...` 通过。
- 实际渲染检查：仪表盘、设置、用户、商业化在 1440×1000 与 390×844 下无横向溢出；深色模式可读。
- 25 个后台页面逐一访问均返回 200，无模板渲染错误或控制台错误。
- 修复 `/admin/login` 渲染失败：后台登录数据补上 `PasswordResetEnabled`，找回密码入口按站点设置显隐。
- 命令面板可用 `⌘K` 打开、键盘上下选择、Enter 跳转。
- 设置 Toggle 修改后出现未保存浮条；分类标签跳转定位正确。
- 用户勾选后浮动批量条出现。
