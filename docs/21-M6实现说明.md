# M6 实现说明：SEO、站点设计与页面

M6 在 M5 之上补齐 SEO 基础设施、可配置站点导航/静态页/公告，以及页面级元数据与结构化数据。

## 1. 交付范围

| 能力 | 实现 |
| --- | --- |
| 标题模板 | `seo.title_template`，支持 `{title}` / `{site}` |
| Meta | description 回退、canonical、OG、Twitter Card、文章时间 |
| 结构化数据 | WebSite + SearchAction、DiscussionForumPosting、BreadcrumbList、Person、Product/Offer |
| robots.txt | 动态生成，私有路径 Disallow，可追加自定义规则 |
| Sitemap | 索引 + 主题/板块/标签/用户/静态页五个分片 |
| RSS | 全站、板块、标签、用户四类 Feed |
| 索引矩阵 | 搜索/筛选/私信/通知/后台/收银台 noindex；空板块/空标签 noindex；删除主题 410 |
| 站点页面 | Markdown 静态页，`/:slug`，后台增删改与发布/草稿 |
| 导航 | 顶部/页脚导航由设置驱动，后台按行编辑，权限可见性 |
| 公告 | 全站公告横幅 |
| 后台 | `/admin/seo` 诊断、`/admin/site` 页面与导航 |

## 2. SEO 渲染

### 标题与描述

- 所有前台页面统一通过 `Data.SetPageTitle(title, template)` 应用 `seo.title_template`。
- 首页、板块、标签、主题、用户、定价页分别设置描述；描述截断到 160 字符。
- 主题页 `og:type=article` 并输出 `article:published_time` / `article:modified_time`。

### Canonical 与索引

- `site.general.url` 配置后生成绝对 canonical；分页页 canonical 保留 `?page=N`。
- 搜索页、筛选页 `noindex,follow`。
- 私信、通知、设置、收藏、积分、订单、订阅、收银台、后台均 `noindex,nofollow`（部分使用独立布局固定 noindex）。
- 空板块、空标签 `noindex,follow`。
- 用户主页受 `seo.index_users` 控制，非 active 用户强制 noindex。
- 已删除主题返回 **410 Gone**，不再返回 404；sitemap 同步移除。

### 结构化数据

| 页面 | JSON-LD |
| --- | --- |
| 首页 | `WebSite` + `SearchAction` |
| 板块/标签/静态页 | `BreadcrumbList` |
| 主题 | `DiscussionForumPosting` + `BreadcrumbList`（`@graph`） |
| 用户 | `Person` |
| 定价页 | 每个上架商品一个 `Product` + `Offer` |

JSON-LD 通过 `encoding/json` 序列化，`<`、`>`、`&` 自动转义，避免脚本注入。

## 3. Sitemap 与 robots

### Sitemap

- `/sitemap.xml` 为索引，包含：
  - `/sitemap-topics.xml`
  - `/sitemap-categories.xml`
  - `/sitemap-tags.xml`
  - `/sitemap-users.xml`
  - `/sitemap-pages.xml`
- 主题分片条件：未删除、状态 `open/closed/archived`、主题与板块均公开。
- 标签分片仅包含 `topic_count > 0`；用户分片受 `seo.index_users` 控制。
- 单分片上限 50,000 条，按更新时间倒序；关闭 sitemap 后所有分片返回 404。
- URL 使用 `url.PathEscape` 处理非 ASCII slug。

### robots.txt

```
User-agent: *
Allow: /
Disallow: /admin
Disallow: /api
Disallow: /install
Disallow: /search
Disallow: /settings
Disallow: /notifications
Disallow: /messages
Disallow: /checkout
Disallow: /billing
...
Sitemap: {base}/sitemap.xml
```

- 支持 `seo.robots_extra` 追加规则（如 Crawl-delay、特定爬虫）。
- Sitemap 行仅在 `seo.sitemap_enabled` 开启时输出。

## 4. RSS

| 路径 | 内容 |
| --- | --- |
| `/feed.xml` | 全站最新 30 条公开主题 |
| `/c/:slug/feed.xml` | 板块最新主题 |
| `/tags/:slug/feed.xml` | 标签最新主题 |
| `/u/:username/feed.xml` | 用户最新主题 |

RSS 2.0 + Atom self link，包含标题、链接、摘要、作者、发布时间；仅输出公开板块中未删除且状态正常的主题。

## 5. 静态页与导航

### 静态页

- 表 `pages`：`slug` 唯一、`title`、`body_raw`、`body_html`、`status`、SEO 覆盖字段。
- 公开路由 `/:slug`，仅渲染 `published` 页面；正文经 goldmark + bluemonday 清洗。
- 旧地址 `/p/:slug` 永久 301 到 `/:slug`，历史链接与搜索引擎收录可平滑迁移。
- 后台保存的导航中若存在 `/p/...`，启动时自动改写为根路径。
- 首次启动自动创建 `about`、`privacy`、`terms` 三篇已发布占位页。
- 后台 `/admin/site` 支持新建、编辑、删除、草稿/发布切换。
- 静态页进入 sitemap-pages 分片。

### 导航

- 设置键 `site.nav.header` / `site.nav.footer` 存储 JSON 数组。
- 后台按行编辑：`标签|链接|权限(可选)`；`http(s)` 开头自动识别为外链。
- 导航项支持权限可见性；为空时使用内置默认导航。
- 修改后即时生效（设置缓存失效）。

### 公告

- `site.general.announcement` 输出在页头下方，纯文本自动转义。

- `go build ./...`

  8. 后台创建静态页 `/help` 正常渲染并进入 sitemap；旧 `/p/help` 301 到 `/help`；
  9. 后台保存 UTF-8 导航后页头即时更新；
