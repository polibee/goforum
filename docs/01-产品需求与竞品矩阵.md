# 01 产品需求与竞品功能矩阵

## 1. 产品定位

GoForum 面向**中小型技术社区、资源分享社区与垂直兴趣社区**，提供可自托管、可深度定制、可商业化的论坛系统。

三个差异化点：

1. **部署极简**：单二进制 + SQLite 即可运行；需要时切换 MySQL/PostgreSQL，不改代码。
2. **运营完整**：不止讨论，内置积分、等级、邀请、签到、抽奖、悬赏、付费内容与订阅。
3. **可持续演进**：模块化单体 + 支付渠道注册表 + 设置驱动站点，新增功能与渠道不推翻核心。

## 2. 目标用户与角色

| 角色 | 说明 | 典型诉求 |
|---|---|---|
| 游客 | 未登录访问者 | 浏览公开内容、搜索、看排行榜、注册 |
| 注册用户 TL0 | 新注册，受限 | 完善资料、发首个主题、通过新手引导 |
| 注册用户 TL1–TL4 | 随活跃度晋升 | 正常发帖互动、参与治理、获得徽章 |
| 版主 | 板块级管理者 | 处理举报、移动/合并/删除主题、禁言 |
| 分类版主 | 指定板块的版主 | 只在本板块内行使管理权 |
| 管理员 | 站点运营者 | 用户、内容、审核、运营、商业化配置 |
| 超级管理员 | 站点所有者 | 站点设置、密钥、支付渠道、维护模式 |
| 运营 | 活动与内容运营 | 公告、徽章、抽奖、优惠券、数据报表 |
| 财务/客服 | 商业化相关 | 订单、退款、对账、发票（可选） |

## 3. 核心场景

1. **发现内容**：首页信息流（最新/热门/关注/未读）→ 板块/标签筛选 → 主题详情 → 相似主题推荐。
2. **创作内容**：发帖 → Markdown 编辑与预览 → 上传图片/附件 → 选择板块与标签 → 发布/定时发布。
3. **交流互动**：回复、引用、@提及、点赞、收藏、关注、私信、通知。
4. **社区治理**：举报 → 审核队列 → 版主处理 → 审计记录 → 申诉。
5. **运营增长**：邀请注册、签到、积分任务、等级、徽章、抽奖、悬赏。
6. **商业化**：购买积分/VIP/邀请码/付费内容 → 收银台 → 支付回调 → 权益发放 → 对账退款。
7. **站务配置**：站点信息、注册策略、板块标签、导航页面、主题品牌、SEO、邮件、存储。

## 5. 功能优先级

### P0（首个可上线版本）

- auth：邮箱注册/验证、登录、找回密码、用户组、信任等级、禁言封禁、会话管理
- community：板块、标签、主题、回复、编辑历史、草稿、阅读状态、置顶/精华/锁定/归档、投票
- engagement：点赞、收藏
- messaging：私信会话
- notification：站内通知、@提及、回复提醒
- moderation：举报、审核队列、版主工具、审计日志、敏感词、新用户审核
- media：图片/附件上传、缩略图、本地存储
- search：关键词搜索、板块/标签/用户筛选、排序
- admin：概览、内容、用户、审核、板块标签、设置、SEO
- 站点设计：品牌、主题色、导航、页脚、静态页、公告
- SEO：SSR、canonical、Meta、OG、JSON-LD、sitemap、robots、RSS
- 支付：余额、人工确认、支付宝、微信（含订单、回调、退款、对账基础）

### P1

- OAuth、2FA、关注/粉丝、通知级别、邮件摘要、SSE
- 标签组与同义词、慢速模式、相似主题、定时发布、隐藏内容、表情、收藏提醒
- 信任等级自动晋升、积分与等级、签到、邀请、勋章、悬赏、VIP/订阅、付费内容
- 全文检索三方言完整实现、热词、搜索建议
- 小黑屋公示、申诉、风控规则
- MySQL/PostgreSQL 生产部署与压测

### P2

- 抽奖、优惠券、交易区、发票
- 多语言、PWA、Webhook、插件化扩展点
- 账号注销与数据导出、申诉流程

## 6. 非功能需求

### 6.1 性能

| 指标 | 目标 |
|---|---|
| 首页 TTFB（缓存命中） | ≤ 50 ms |
| 首页 TTFB（未命中） | ≤ 200 ms |
| 主题页 LCP | ≤ 2.5 s（4G） |
| API p95 | ≤ 150 ms |
| 首屏 HTML（gzip） | ≤ 100 KB |
| 单实例并发读 | ≥ 1000 |
| 图片 | 懒加载、AVIF/WebP、srcset |

### 6.2 容量与可用性

- 设计容量：100 万用户、1000 万主题+回复、日活 10 万。
- 可用性目标：99.9%（单机 + 备份；不含计划维护）。
- 单机 SQLite 推荐 ≤ 20 万主题；超过后迁移 MySQL/PostgreSQL。

### 6.3 安全

- 对齐 OWASP ASVS L2；所有输入校验、输出转义、参数化查询。
- 密码 Argon2id；会话轮换；2FA 可选强制。
- 支付不接触卡号，回调验签 + 金额校验 + 幂等。
- 全量管理操作审计；密钥加密存储。

### 6.4 SEO

- 每个页面类型明确 index/noindex；公开内容可被抓取。
- 结构化数据覆盖主题、问答、面包屑、用户、组织。
- Sitemap 自动生成并排除私有内容；删除内容返回 410。

### 6.5 可访问性

- WCAG 2.1 AA：键盘可达、焦点可见、对比度达标、aria-live 通知、跳转链接。
- 快捷键：`Ctrl+K` 搜索、`j/k` 移动、`r` 回复、`g h` 回首页。

### 6.6 国际化

- 默认简体中文；文案集中管理，预留 en-US。
- 时间按用户时区展示；金额按币种格式化。

### 6.7 合规

- 提供隐私政策、用户协议、内容规则页面模板。
- 支持内容删除与账号注销；IP 保留期限可配置。
- 真实收款需商户资质，系统仅提供技术能力。

## 7. 成功指标

| 指标 | 定义 | 目标（上线 90 天） |
|---|---|---|
| 激活率 | 注册后 24h 内发帖或回复 | ≥ 30% |
| 次日留存 | 注册次日回访 | ≥ 25% |

| 内容供给 | 日新增主题+回复 | 按社区规模设定 |
| 搜索满意度 | 搜索后点击率 | ≥ 45% |
| 审核时效 | 举报到处理中位时长 | ≤ 12 h |
| 支付成功率 | 下单到支付成功 | ≥ 95% |
| 核心 Web Vitals | LCP/CLS/INP | 全绿 |

## 8. 范围边界

**不做**：原生移动 App、插件市场、多租户 SaaS、多站点、自动续费扣款、多币种汇率换算、完整电商/物流。

**可延后**：交易区担保、发票、PWA、多语言、Webhook、申诉。

## 9. 假设与依赖

- 部署方具备域名、TLS 证书与邮件服务（或可跳过邮件验证）。
- 支付渠道需自行申请商户号并完成合规审核。
- 全文检索优先使用数据库原生能力；数据量超限时接入外部搜索引擎。
- 图片与附件默认本地存储，生产建议对象存储 + CDN。
