# 07 页面与交互规格

> 每个页面按 **十要素** 描述：URL、布局、数据、权限、区块、交互、状态、SEO、移动端、验收。后台页面见 [08-后台管理面板设计](./08-后台管理面板设计.md)。

## 1. 页面清单

| 分组 | 页面 | 优先级 |
|---|---|---|
| 内容浏览 | 首页、板块页、标签页、主题详情、搜索结果、静态页 | P0 |
| 内容创作 | 发帖、编辑主题/回复 | P0 |
| 用户 | 用户主页、通知中心、私信列表、私信会话 | P0 |
| 认证 | 登录、注册、邀请注册、找回/重置密码、邮箱验证、2FA | P0 |
| 设置 | 资料、安全、通知与偏好、API Token | P0/P1 |
| 商业化 | 定价/充值、收银台、订单/账单、订阅、付费内容解锁 | P1 |
| 运营 | 悬赏、抽奖、积分/签到、小黑屋 | P1/P2 |
| 系统 | 404/403/500、维护页 | P0 |

## 2. 内容浏览

### 2.1 首页

| 要素 | 规格 |
|---|---|
| URL | `/`，查询参数 `?tab=latest|hot|following|unread&category=&tag=` |
| 布局 | `shell`，主内容 + 右侧边栏（≥lg） |
| 数据 | 站点设置、导航、公告、信息流（游标）、板块摘要、热门标签、站点统计、在线人数 |
| 权限 | 公开；`following`/`unread` 需登录，未登录时显示登录引导 |
| 区块 | 公告横幅 → 筛选 Tabs → 主题列表 → 加载更多；侧栏：板块导航、热门标签、统计、社区规则 |
| 交互 | Tab 切换写入 URL；无限滚动（IntersectionObserver）；点击标题进入主题；未读圆点；发帖按钮 |
| 状态 | 骨架屏 8 行；空态（关注流为空时推荐板块）；错误重试；未登录提示 |
| SEO | `index,follow`；canonical 自指；`WebSite + SearchAction` 结构化数据；分页 `?page=` 时 canonical 自指 |
| 移动端 | 单列卡片；Tabs 横向滚动；底部标签栏；发帖 FAB |
| 验收 | 首屏 TTFB ≤ 200ms；Tab 可分享；未读数与服务端一致；无限滚动不重复 |

### 2.2 板块页

| 要素 | 规格 |
|---|---|
| URL | `/c/:slug`，`?sort=latest|hot|top&tag=` |
| 布局 | `shell`，板块头图/描述 + 主题列表 |
| 数据 | 板块信息、子板块、版主、主题列表、板块规则、关注状态 |
| 权限 | 公开板块公开；私有板块无权限返回 404；只读板块隐藏发帖按钮 |
| 区块 | 面包屑 → 板块头部（名称/描述/统计/关注/发帖）→ 子板块 → 筛选 → 列表 → 分页 |
| 交互 | 关注/取消；排序与标签筛选；版主入口；`topic.create` 校验后跳转发帖 |
| 状态 | 空板块引导发帖；无权限 404；加载骨架 |
| SEO | `index,follow`（空板块 `noindex`）；canonical 自指；面包屑结构化数据 |
| 移动端 | 头部压缩为两行；筛选横向滚动 |
| 验收 | 私有板块在列表/搜索/站点地图均不可见；关注状态即时更新 |

### 2.3 标签页

| 要素 | 规格 |
|---|---|
| URL | `/tags/:slug`，`?sort=` |
| 布局 | `shell` |
| 数据 | 标签、标签组、相关标签、主题列表、关注状态 |
| 权限 | 公开；受限标签按板块权限过滤 |
| 区块 | 标签头（颜色/描述/主题数/关注）→ 相关标签 → 列表 |
| 交互 | 关注标签；切换排序；点击相关标签 |
| 状态 | 空标签 `noindex`；错误重试 |
| SEO | 正常 `index`；空标签 `noindex,follow`；canonical 自指 |
| 移动端 | 标签云横向滚动 |
| 验收 | 标签改名后旧 slug 301；受限内容不泄露 |

### 2.4 主题详情

| 要素 | 规格 |
|---|---|
| URL | `/t/:id-:slug?page=&post=` |
| 布局 | `shell`，正文 + 右侧目录/相似主题（≥xl） |
| 数据 | 主题、板块、标签、楼层流、投票、阅读状态、关注级别、相似主题、版主权限 |
| 权限 | 可见性校验；锁定主题只读；待审核仅作者与版主可见 |
| 区块 | 面包屑 → 标题区（状态徽章/标签/版主操作）→ 投票 → 楼层流（引用/回复/点赞/收藏/举报/编辑）→ 回复框 → 相似主题 |
| 交互 | 楼层锚点；引用插入；@补全；点赞乐观更新；收藏/关注；分享复制链接；阅读进度上报；版主菜单（置顶/精华/锁定/移动/合并/拆分/删除）；已解决标记 |
| 状态 | 删除返回 410；无权限 404；锁定显示只读提示；楼层加载骨架；举报成功 toast |
| SEO | `DiscussionForumPosting`（问答用 `QAPage`）；canonical 指向规范 URL；分页自指；首楼摘要作 description |
| 移动端 | 楼层卡片化；底部固定回复按钮；图片点击全屏 |
| 验收 | 并发回复楼层不重号；引用内容可跳转；举报后进入队列；410 正确 |

### 2.5 搜索结果

| 要素 | 规格 |
|---|---|
| URL | `/search?q=&type=&category=&tag=&author=&sort=&page=` |
| 布局 | `shell`，筛选侧栏 + 结果列表 |
| 数据 | 结果、总数、耗时、热词、建议、筛选选项 |
| 权限 | 公开（可配置仅登录）；私有内容过滤 |
| 区块 | 搜索框 → 筛选 → 结果（标题/摘要高亮/作者/时间/统计）→ 分页 |
| 交互 | 输入防抖 250ms；筛选即时；结果高亮；无结果推荐热词 |
| 状态 | 空结果给建议；超时提示重试；深分页提示缩小范围 |
| SEO | `noindex,follow`；不进入 sitemap；`rel=prev/next` |
| 移动端 | 筛选抽屉；结果卡片 |
| 验收 | 私有内容零泄露；5 秒内反映新内容；深分页受控 |

### 2.6 静态页

| 要素 | 规格 |
|---|---|
| URL | `/:slug`（about/privacy/terms/help/rules） |
| 布局 | `shell`，窄阅读容器 |
| 数据 | 页面 Markdown/HTML、目录、更新时间、SEO 覆盖 |
| 权限 | 公开 |
| 区块 | 标题 → 目录 → 正文 → 更新时间 → 相关页面 |
| 交互 | 目录锚点；外链 `rel` 策略；打印样式 |
| 状态 | 不存在 404；草稿仅管理员预览 |
| SEO | `index`；可单独设置 title/description/og；`Article` 结构化数据 |
| 移动端 | 目录折叠 |
| 验收 | 后台编辑后即时生效；XSS 清洗通过 |

## 3. 内容创作

### 3.1 发帖

| 要素 | 规格 |
|---|---|
| URL | `/new?category=:slug` |
| 布局 | `shell`，全宽编辑器（移动端全屏） |
| 数据 | 板块列表与权限、标签组、草稿、用户偏好（编辑器模式） |
| 权限 | `topic.create` + 板块权限 + 信任等级；禁言/封禁拦截 |
| 区块 | 板块选择 → 标题 → 工具栏（粗体/链接/代码/图片/附件/表情/投票）→ 编辑区 → 预览 → 标签 → 发布 |
| 交互 | Markdown 预览；粘贴/拖拽上传；@补全；草稿每 3 秒本地 + 30 秒服务端保存；标签校验；发布前二次确认（可选） |
| 状态 | 校验错误字段级提示；上传中占位；发布中禁用；失败保留内容 |
| SEO | `noindex`；发布后跳转主题页 |
| 移动端 | 全屏编辑；工具栏底部固定；图片直接调用相机 |
| 验收 | 刷新后草稿恢复；重复提交只创建一次；标签规则生效 |

### 3.2 编辑主题/回复

| 要素 | 规格 |
|---|---|
| URL | `/t/:id/edit`、`/posts/:id/edit` |
| 布局 | 同发帖；回复使用弹层或独立页 |
| 数据 | 原文、编辑历史、编辑时限、权限 |
| 权限 | 作者在时限内；版主随时；锁定主题限制 |
| 区块 | 标题/正文编辑 → 编辑说明 → 保存/取消 → 历史入口 |
| 交互 | 离开未保存提示；保存后局部刷新楼层；版主编辑标记 |
| 状态 | 超时提示申请版主；冲突（已被编辑）提示合并 |
| SEO | `noindex` |
| 移动端 | 同发帖 |
| 验收 | 每次编辑生成修订；历史可对比；编辑后索引更新 |

## 4. 用户与消息

| 要素 | 规格 |
|---|---|
| URL | `/u/:username`，`/u/:username/:tab`（topics/replies/likes/bookmarks/badges） |
| 布局 | `shell`，头部卡片 + Tabs |
| 数据 | 资料、统计、用户组、信任等级、等级、徽章、内容列表、关注状态、隐私设置 |
| 权限 | 公开资料；隐私项按设置隐藏；被封禁用户显示状态 |
| 区块 | 头像/封面 → 用户名/组/等级 → 简介/加入时间/统计 → 关注/私信 → Tabs → 列表 |

| 移动端 | 头部紧凑；Tabs 横向滚动 |
| 验收 | 隐私设置生效；封禁用户不可私信；统计与内容一致 |

### 4.2 通知中心

| 要素 | 规格 |
|---|---|

| 交互 | 点击已读并跳转；全部已读；SSE 实时插入；分组折叠（同主题多条） |
| 状态 | 空态；SSE 断线提示并降级轮询；加载更多 |
| SEO | `noindex` |
| 移动端 | 单列；滑动标记已读（可选） |
| 验收 | 未读数准确；重复事件不重复；静音后无通知 |

### 4.3 私信列表

| 移动端 | 全屏会话；返回列表 |
| 验收 | 消息顺序正确；已读同步；举报可追溯 |

## 5. 认证

### 5.1 登录

| 要素 | 规格 |
|---|---|
| URL | `/login?next=` |
| 布局 | `auth` |
| 数据 | 站点品牌、OAuth 提供商、注册入口 |
| 权限 | 游客；已登录跳转 `next` 或首页 |
| 区块 | Logo → 账号/邮箱 → 密码 → 记住我 → 登录 → 第三方登录 → 忘记密码/注册 |
| 交互 | 回车提交；密码可见切换；失败计数提示；2FA 跳转；`next` 白名单校验 |
| 状态 | 字段错误；锁定提示倒计时；OAuth 失败提示 |
| SEO | `noindex` |
| 移动端 | 单列居中；键盘适配 |
| 验收 | 不泄露账号是否存在；限流生效；登录后会话轮换 |

### 5.2 注册

| 要素 | 规格 |
|---|---|
| URL | `/register` |
| 布局 | `auth` |
| 数据 | 注册模式、站点规则、邀请码（如有） |
| 权限 | 游客；关闭注册时显示说明 |
| 区块 | 用户名 → 邮箱 → 密码 → 确认密码 → 协议勾选 → 注册 → 已有账号登录 |
| 交互 | 实时用户名/邮箱可用性（防枚举可只在前端校验格式）；密码强度；邀请码校验；提交后进入验证页 |
| 状态 | 审核模式提示等待；邮件发送失败可重试 |
| SEO | `noindex` |
| 移动端 | 单列 |
| 验收 | 三种模式行为正确；重复注册被拒；协议未勾选不可提交 |

### 5.3 邀请注册

| 要素 | 规格 |
|---|---|
| URL | `/invite/:code` |
| 布局 | `auth` |
| 数据 | 邀请人、邀请码状态、预填邮箱 |
| 权限 | 游客；无效/过期/已用显示原因 |
| 区块 | 邀请人信息 → 注册表单 → 提交 |
| 交互 | 校验邀请码；注册成功标记已用；邀请人获得奖励 |
| 状态 | 失效提示；注册关闭提示 |
| SEO | `noindex` |
| 移动端 | 单列 |
| 验收 | 邀请码一次性；并发使用只成功一次；奖励只发一次 |

### 5.4 找回/重置密码

| 要素 | 规格 |
|---|---|
| URL | `/forgot-password`、`/reset-password/:token` |
| 布局 | `auth` |
| 数据 | 站点品牌、令牌状态 |
| 权限 | 游客 |
| 区块 | 邮箱输入 → 发送提示；重置页：新密码 + 确认 |
| 交互 | 统一成功文案（不暴露邮箱是否存在）；令牌一次性；重置后失效所有会话 |
| 状态 | 令牌过期/已用提示重新申请 |
| SEO | `noindex` |
| 移动端 | 单列 |
| 验收 | 枚举防护；令牌过期；旧会话全部失效 |

### 5.5 邮箱验证

| 要素 | 规格 |
|---|---|
| URL | `/verify-email/:token` |
| 布局 | `auth` |
| 数据 | 令牌状态、用户邮箱掩码 |

### 5.6 2FA 挑战

## 10. 通用交互验收

1. 所有页面在 320px–1440px 可用，无横向滚动。
