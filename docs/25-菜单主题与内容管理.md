## 2. 导航菜单管理

### 数据模型

`nav_items`：

| 字段 | 说明 |
| --- | --- |
| `location` | `header` 或 `footer` |
| `label` | 显示名称 |
| `url` | 内链或外链 |
| `permission` | 可选权限键，留空所有人可见 |
| `sort` | 升序 |
| `enabled` | 启用/停用 |
| `external` | 外链自动识别 |
| `section` | 页脚分组名称；前台按分组成列，留空归入无标题列 |

`sidebar_widgets`：

| 字段 | 说明 |
| --- | --- |
| `title` | 卡片标题 |
| `type` | `links` 或 `text` |
| `body` | links：每行 `名称|链接`；text：纯文本 |
| `sort` | 升序 |
| `enabled` | 启用/停用 |

### 后台

`/admin/site`：

- 页眉/页脚菜单：添加、编辑、删除、启用/停用
- 页脚菜单可填写「页脚分组」，前台按分组渲染多列页脚
- 侧边栏卡片：添加、编辑、删除、启用/停用
- 不要求管理员编写 JSON
- 修改后立即失效缓存，前台即时生效

提示：添加第一条自定义菜单后会替换内置导航；删除全部后恢复内置导航。

### 兼容迁移

旧版本使用设置项 `site.nav.header` / `site.nav.footer` 存储 JSON。启动时若 `nav_items` 为空，会自动把旧 JSON 迁移为数据库行，然后清空旧设置，避免删除后重启又复活。

## 3. 侧边栏

- 论坛首页右侧保留内置“板块 / 热门标签”卡片。
- 自定义卡片按 `sort` 追加在内置卡片之后。
- 链接列表卡片解析 `名称|链接`，文本卡片保留换行。
- 卡片内容由管理员维护，不做 Markdown 渲染，避免注入风险。

## 4. 简洁帖子链接

- 主题新增自增 `number`，前台链接统一为 `/t/{number}`，例如 `/t/1`。
- 旧链接 `/t/{ulid}-{slug}` 与 `/t/{ulid}` 仍可访问，并 **301** 到短链接。
- sitemap、RSS、列表页、用户主页、后台主题列表均输出短链接。
- `topic_numbers` 表负责分配自增编号；启动时为历史主题自动补号。
- 搜索引擎与新分享链接只使用短地址。

## 5. 主题预设

设置项：`site.theme.preset` 作为站点默认值；访客可通过页头「主题外观」菜单切换，选择写入 Cookie `gf_theme`，优先于站点默认。可选：

| 值 | 风格 |
| --- | --- |
| `default` | 默认蓝白风格 |
| `wechat` | 微信风格：灰底、微信绿、圆角卡片、弱阴影 |
| `douyin` | 抖音风格：深色底、抖音红/青、更锐利卡片、按钮光晕 |
| `minimal` | 简约白：纯白底、黑色强调色、扁平卡片、无阴影 |

实现：

- 页头菜单：默认风格 / 微信绿 / 抖音简约 / 浅色-深色切换，当前项带 ✓。
- `<html data-theme="...">` 输出当前访客预设。
- Tailwind 品牌色改为 CSS 变量（`--gf-brand-50` … `--gf-brand-950`），预设通过变量和少量组件覆盖实现。
- `douyin` 同时强制深色模式。
- 自定义品牌色在 `default` 下生效；选择预设时由预设覆盖品牌色。

扩展新主题：

1. 在设置枚举中增加值；
2. 在 `web/css/app.css` 增加 `html[data-theme="xxx"]` 变量与组件覆盖；
3. 重新构建 CSS。

## 6. 用户签名

- `users.signature`，最多 300 字符、6 行，支持 Markdown。
- 个人资料页签名输入框支持 **粗体**、*斜体*、`代码`、链接、引用、列表；不支持图片、标题和表格。
- 保存时由服务端 `RenderSignature` 渲染，再经 bluemonday 白名单清洗；链接自动 `nofollow noreferrer`。
- 主题页每条回复正文下方显示签名，使用分隔线与浅色文本，参考 NodeSeek 的展示方式。
- 签名按用户 ID 批量读取，不产生逐楼查询。

## 7. 帖子页改版（参考 NodeSeek）

- 页面主体改为「帖子内容 + 右侧栏」两栏布局，右侧栏在桌面端吸顶。
- 右侧栏包含：
  - 「关于本帖」：板块、作者、发布时间、浏览量、回复数、标签
  - 管理员配置的侧边栏卡片（链接列表/文本）
- 回复采用 NodeSeek 式紧凑列表：头像、用户名、TL 等级、楼主标识、时间同一行，楼层号靠右。
- 所有回复放在同一张卡片内，用分隔线区分，不再一回复一卡片。
- 每条回复提供「回复」入口，携带 `?quote=<post_id>#reply` 自动引用原帖内容。
- 「全部回复 / 只看楼主」切换：`?op=1` 仅显示楼主回复，分页统计同步。
- 桌面端右下角提供「回到顶部」浮动按钮。
- 移动端保持同一行作者信息；右侧栏移动到正文下方。
- 首页/板块/标签列表新增「最新 / 热门」排序切换。
- 签名位于正文与操作之间，弱化显示。

## 8. 编辑器

- 发帖与编辑回复共用编辑器组件：
  - 编辑 / 预览切换
  - 工具栏：粗体、斜体、代码、引用、列表、标题、链接
  - 服务端 Markdown 预览，经 bluemonday 清洗后返回
  - localStorage 草稿自动保存（600ms 防抖），支持清除草稿
- 上传图片仍复用原上传组件，插入 Markdown 图片语法。

## 9. 后台内容编辑

### 主题编辑

`GET /admin/topics/:id/edit`：

- 标题
- 板块
- 状态（开放/关闭/归档/隐藏/待审核）
- 首楼正文（Markdown）
- 保存时：更新标题/板块/状态，并调用版主编辑逻辑写入修订记录、重新渲染正文。

后台主题列表新增“编辑”入口。

### 回复编辑

后台回复列表新增“编辑”链接，复用 `/posts/:id/edit` 的版主编辑能力，保留修订记录。

## 10. 验证

- 后台添加页眉菜单后前台即时出现；删除后消失。
- 侧边栏卡片添加后出现在首页右侧；链接与文本类型均正常。
- 微信主题：灰底、绿色按钮、圆角卡片。
- 抖音主题：深色底、红/青强调色、按钮光晕。
- 签名保存后在每条回复下展示；超过 300 字符或 6 行返回校验错误。
- 后台主题编辑保存后标题/板块/正文更新，并生成修订记录。
- 后台回复编辑链接可打开编辑页。
- 全部页面渲染无模板错误，`go build` / `go test` / `go vet` 通过。

## 11. 当前边界

- 主题为 CSS 预设，不提供可视化拖拽编辑器。
- 侧边栏卡片仅支持链接列表与纯文本，不支持 HTML/脚本。
- 菜单不支持多级嵌套；页脚分组仅一层。
- 后台仍以中文为主；英文后台需补齐 `admin.json`。
