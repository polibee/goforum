# 09 站点设置与通用站点设计

> 目标：**同一份代码服务不同社区**。站点名称、品牌、颜色、导航、布局、页面、注册策略、邮件、存储、SEO 全部由后台配置驱动，禁止硬编码。

## 1. 设置框架

### 1.1 设置项模型

```go
type Definition struct {
    Namespace   string        // 模块或 site
    Key         string        // 点分键，如 general.site_name
    Group       string        // 15 组之一
    Type        Type          // string/text/bool/int/enum/json/secret/upload/color/duration/url/email
    Default     any
    Validate    []Rule
    Permission  string        // settings.<group>
    Restart     bool          // 是否需要重启
    Secret      bool          // 是否加密存储与掩码
    EnvOverride string        // 对应环境变量名
    Description string
}
```

完整键名：`<namespace>.<key>`，例如 `site.general.name`、`community.post.max_length`、`billing.payment.currency`。

### 1.2 类型与校验

| 类型 | 存储 | 校验 |
|---|---|---|
| `string` | 文本 | 长度、正则、必填 |
| `text` | 长文本 | 长度、Markdown 白名单 |
| `bool` | 布尔 | — |
| `int` | 整数 | 最小/最大 |
| `enum` | 字符串 | 枚举集合 |
| `json` | JSON | schema 校验 |
| `secret` | 加密文本 | 非空、格式 |
| `upload` | 附件 ID | MIME、尺寸 |
| `color` | `#RRGGBB` | 对比度检查 |
| `duration` | 秒 | 范围 |
| `url` | 文本 | scheme 白名单 |
| `email` | 文本 | 格式 |

### 1.3 优先级

```
默认值 < 数据库设置 < 环境变量 < 启动参数
```

- 基础设施连接信息（DSN、Redis、S3、SMTP 密码）优先环境变量，数据库只存非敏感配置。
- `secret` 类型：环境变量优先；若入库则 AES-GCM 加密，界面只显示“已配置”。
- 启动时校验全部设置；非法值拒绝启动并输出键名与原因。

### 1.4 读取与缓存

- 启动加载全量快照到内存，读操作零 DB。
- 保存后版本号 +1，通过缓存失效广播（Redis pub/sub 或实例间轮询）刷新。
- 模板统一通过 `Site` 对象读取；组件不得直接查 `settings` 表。

### 1.5 保存流程

1. 前端只提交变更键（差异保存）。
2. 服务端校验权限、类型、范围、跨字段约束。
3. 写入 `settings` 与 `setting_revisions`（旧值/新值/操作人）。
4. 更新版本号、失效缓存、广播。
5. 需要重启的项在界面标记“重启后生效”。
6. 返回变更摘要；冲突（版本不一致）提示刷新后重试。

### 1.6 导入导出

- 导出 YAML：按分组，密钥字段以 `***` 占位，不导出真实密钥。
- 导入：先 dry-run 展示差异与校验结果，确认后应用；密钥字段留空表示不修改。
- 支持恢复默认（按组/单项），恢复前展示将变化的键。

## 3. 通用站点设计

### 3.1 品牌

- **Logo**：亮色/暗色两套，建议 SVG 或 2x PNG；未上传时用站点名文字 Logo。
- **Favicon**：自动生成 16/32/180/192/512 多尺寸；支持 ICO/PNG。
- **默认分享图**：1200×630；未上传时按模板自动生成（站点名 + 标语 + 品牌色）。
- **邮件头图**：600px 宽；未上传时用品牌色块 + 文字。
- 所有品牌资源走 `media` 模块，支持 CDN。

### 3.2 主题与外观

- **色板**：后台选主色/强调色，系统生成 50–900 色阶并校验对比度；不达标时提示。
- **字体**：系统字体（默认）、衬线、或上传 WOFF2（需授权）；中文字体可选子集。
- **圆角与密度**：全局 token；密度影响列表行高与间距。
- **暗色**：默认模式可设，允许用户切换；首屏服务端渲染避免闪烁。
- **自定义 CSS**：作用域限制，禁止 `@import` 外部不可信源；保存前做语法与危险模式检查。
- **自定义 JS**：仅超级管理员可编辑；通过 nonce 注入；保存需二次确认并记录审计。
- **实时预览**：外观页右侧 iframe 预览，保存前不影响线上。

### 3.3 布局

- **首页模式**：
  - `feed`：信息流 + 侧栏（默认）。
  - `grid`：板块宫格 + 最新主题。
  - `custom`：指定静态页作为首页。
- **侧栏组件**：板块导航、热门标签、统计、在线用户、社区规则、自定义 HTML（超管）；可拖拽排序与显隐。
- **列表密度**：舒适/紧凑；每页条数；是否无限滚动。
- **Hero 区**（可选）：标题、标语、搜索框、主行动按钮；由设置控制。

### 3.4 导航

- 三个位置：顶部、页脚、移动端底部标签。
- 最多 2 级；拖拽排序；每项字段：标签、链接（内链选择器/外链）、图标、权限可见性、新窗口、启用。
- 内链选择器支持板块、标签、页面、外部 URL；外链校验 scheme（仅 http/https）。
- 保存后前台即时生效；导航项无权限时对用户隐藏。
- 移动端底部标签建议 3–5 项（首页/板块/搜索/通知/我的）。

### 3.5 页面与公告

- 静态页：Markdown 编辑、预览、SEO 字段（title/description/og/noindex）、是否显示在导航、发布状态。
- 默认页面模板：关于、隐私政策、用户协议、社区规则、帮助。
- 公告：受众（所有人/游客/登录用户/指定用户组）、开始/结束时间、可关闭、样式（横幅/弹层）。
- 页脚：版权、社交链接、备案号（可配置）、RSS 入口。

### 3.6 邮件品牌

- 发件人名称、回复地址、头图、主色、页脚。
- 模板变量：`{{site_name}}`、`{{user_name}}`、`{{action_url}}`、`{{unsubscribe_url}}`。
- 提供测试发送；退信与投诉进入抑制列表。

### 3.7 PWA（P2）

- manifest：名称、短名称、图标（192/512）、主题色、背景色、启动 URL。
- 可选离线页；不缓存私密页面。
- Service Worker 仅缓存静态资源与离线页，避免缓存个性化 HTML。

## 4. 安装向导

首次启动（无配置文件或数据库为空）进入 `/install`，步骤：

1. **环境检查**：Go 版本、目录可写、扩展、时区。
2. **数据库**：选择 SQLite / MySQL / PostgreSQL；填写连接信息；测试连接；选择“清空并初始化”。
3. **站点信息**：名称、URL、语言、时区、Logo（可跳过）。
4. **管理员账号**：用户名、邮箱、密码；创建超级管理员与默认用户组。
5. **注册策略**：开放/邀请/审核；是否邮箱验证。
6. **邮件（可跳过）**：SMTP 测试。
7. **SEO 基础**：标题模板、描述、是否启用 sitemap。
8. **完成**：写入配置、执行迁移、生成站点设置、锁定安装程序。

约束：

- 安装程序在完成后写入锁文件，重复访问返回 404。
- 数据库连接信息写入配置文件/环境变量，不写数据库。
- 任一步失败可回退，不留下半初始化状态（迁移在事务/可重入脚本中执行）。
- 安装过程写审计日志（本地文件），便于排查。

## 5. 设置驱动的前端契约

模板只读取统一上下文：

```go
type SiteContext struct {
    Name        string
    Tagline     string
    Description string
    URL         string
    Locale      string
    Timezone    string
    LogoLight   string
    LogoDark    string
    Favicon     string
    OGImage     string
    Theme       ThemeTokens
    Nav         NavSet
    Footer      FooterSet
    Features    map[string]bool
    Announcement *Announcement
}
```

- 模板禁止出现硬编码站点名、颜色值、导航链接。
- 颜色通过 CSS 变量注入 `<style nonce>`，Tailwind 使用变量。
- 导航通过循环渲染，权限过滤在服务端完成。
- CI 检查：模板中出现 `GoForum` 等默认站点名（除默认值定义外）视为失败。

---

## 6. 验收标准

1. 每个设置项都有类型、默认值、校验、权限键、审计与是否重启标记。
2. 保存为差异提交；并发修改有版本冲突提示。
3. 密钥类字段加密存储、界面掩码、导出不泄露。
4. 修改站点名/Logo/主题色/导航后，前台无需改代码即时生效。
5. 恢复默认与导入导出可用，导入前有 dry-run 差异。
6. 安装向导可在三种数据库下完成，重复访问被锁定。
7. 前台模板无硬编码品牌、颜色、导航。
8. 设置非法时拒绝启动并指出具体键。
