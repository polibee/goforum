# 15 M0 实现说明

> 对应路线图 M0：平台内核 + 模块框架 + 后台外壳 + 设置框架 + 安装向导。本文记录实际落地内容、与设计文档的差异、验证结果与 M1 入口。

## 1. 已实现能力

| 能力 | 实现 | 主要路径 |

| 模块契约 | `Module` 七项：名称/依赖/模型/路由/后台/权限/设置/订阅 | `internal/app/module.go` |
| 模块注册 | 名称唯一、依赖存在、DFS 拓扑排序、环检测 | `internal/app/registry.go` |
| 设置框架 | 类型/默认值/校验/分组/DB 覆盖/差异提交/变更审计/密钥掩码 | `internal/platform/settings` |
| 身份 | 用户表、Argon2id、登录、会话（DB）、CSRF | `internal/modules/auth`、`platform/password`、`platform/session` |

| 后台外壳 | 仪表盘、用户列表、站点设置、模块清单、登录/退出、响应式侧栏 | `internal/modules/admin` |
| 安装向导 | 选库/站点/管理员、写配置、生成 secret_key、热切换路由、安装锁 | `internal/app/install.go` |
| 模板 | 布局（base/auth/admin）、组件、错误页、设置表单 | `web/templates` |
| 资源管线 | Tailwind CLI + esbuild + Alpine CSP build + `embed.FS` | `web/css`、`web/js`、`package.json` |

| 测试 | 配置、密码、设置、身份、模块注册 | `*_test.go` |

## 2. 模块注册现状

当前注册 11 个模块，按依赖顺序：

```
auth → community → media → engagement → messaging
→ notification → moderation → gamification → billing → search → admin
```

- `auth`、`community`、`admin` 有真实实现（community 仅模型与 manifest）。
- 其余为 `placeholder`：已声明依赖、权限键与设置项，用于验证聚合路径；M2–M5 逐步替换为真实实现。
- 后台导航当前仅显示：仪表盘、用户、站点设置、模块清单。未实现页面的模块不注册导航，避免死链。

## 3. 与设计文档的差异（M0 范围）

| 设计 | M0 实现 | 计划 |
|---|---|---|
| goose 分方言 SQL 迁移 | AutoMigrate | M1 引入版本化迁移，生产禁用 AutoMigrate |
| outbox 事件总线 | 内存同步总线 | M1 落 `event_outbox` 表与 Dispatcher |
| 搜索三方言 FTS | `Noop` 引擎 | M2 实现 FTS5 / FULLTEXT / tsvector |
| 缓存/存储/队列/邮件可插拔 | 接口 + 默认实现已定义，尚未接入业务 | M1 上传接入 storage，M2 通知接入 mail/queue |
| 用户组 + 信任等级权限 | 仅超管（`IsSuperAdmin`） | M1 用户组，M3 信任等级 |
| 私信复用 topics | 独立模块规划 | M2 实现 |
| 所有后台页面 | 4 个页面 | M1/M3 按文档补齐 |

## 4. 运行方式

```bash
# 前端资源（首次）
npm install
npm run build

# 启动
go run ./cmd/goforum
```

- 首次访问 `http://127.0.0.1:8080/install` 完成安装。
- Windows 若端口/防火墙受限，使用回环地址：`GF_HTTP_ADDR=127.0.0.1:18080 go run ./cmd/goforum`。
- 默认 SQLite：`data/goforum.db`；配置：`configs/goforum.yaml`（安装时生成）。
- 安装完成后 `/install` 返回 404。

构建单二进制：

```bash
make build      # bin/goforum
```

## 6. 已知事项

- `npm audit` 报告 3 个 moderate（仅开发依赖）；生产产物不包含 node_modules。
- 安装向导写入的配置文件包含 DSN；生产应使用环境变量注入敏感项。
- 当前仅支持 `127.0.0.1` 绑定验证；绑定 `:8080` 时若被 Windows 防火墙拦截，需放行或改用回环地址。
- 会话清理、登录失败锁定、邮箱验证在 M1 补齐。

## 7. M1 入口

1. **auth 完整化**：注册（开放/邀请/审核）、邮箱验证、找回密码、登录失败限流、用户组。
2. **community 服务层**：板块/标签/主题/回复/编辑历史/草稿/阅读状态/投票。
3. **页面闭环**：首页信息流、板块页、主题详情、发帖/编辑、用户主页。
4. **media**：上传、缩略图、本地存储接入。
5. **后台**：主题/回复/板块/标签管理。
6. **测试**：发帖→回复→编辑→删除→恢复；权限与私有板块隔离；无 JS 表单可用。
