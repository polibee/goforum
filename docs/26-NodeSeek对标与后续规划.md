# NodeSeek 对标与后续规划

参考页面：`https://www.nodeseek.com/post-1039512-1`

## 1. 已对齐的能力

| 能力 | 当前实现 |
| --- | --- |
| 简洁帖子地址 | `/t/{number}`，旧地址 301 |
| 右侧栏 | 关于本帖 + 管理员侧边栏卡片，桌面吸顶 |
| 紧凑回复列表 | 单卡片 + 分隔线，头像/用户名/TL/OP/时间同一行 |
| 楼层与定位 | `#post-id`、楼层号可点击 |
| 引用回复 | `?quote=<post_id>#reply` 自动填充 Markdown 引用 |
| 只看楼主 | `?op=1` |
| 签名 | 正文下方弱化展示 |
| 表态 | 点赞（基础版） |
| 收藏/关注/举报 | 已有 |
| 用户等级 | TL0–TL4 + 徽章 |
| 深色模式 | 已有，另有微信/抖音主题预设 |
| 移动端 | 响应式，侧边栏下移 |

## 2. 建议新增（按优先级）

### P0：直接影响内容消费体验

1. **多种表态**
   - NodeSeek 使用多个表情表态（赞/踩/感谢等）
   - 当前仅 Like，建议新增 `reactions` 表：`(user_id, target_type, target_id, type)` 唯一
2. **楼中楼 / 嵌套回复**
   - 当前回复是平铺列表，引用只做文本引用
   - 建议 `posts.parent_id`，评论树最多两级，父楼展示子回复折叠
3. **用户悬浮卡**
   - 悬停头像显示等级、注册时间、发帖数、关注按钮
   - 复用 `/api/v1/users/:id/summary`
4. **移动端底部导航**
   - 首页/板块/发布/通知/我的
   - 当前移动端只有顶部折叠菜单
5. **图片灯箱与评论图预览**
   - 点击正文图片放大、左右切换、ESC 关闭
6. **相关主题 / 热门主题侧栏**
   - 按标签或板块推荐，作为内置侧边栏卡片
7. **通知实时化**
   - 当前通知为请求时读取；建议 SSE `/api/v1/notifications/stream`

### P1：社区运营与表达

1. 最佳答案 / 结帖（已有 `is_solved` 字段，缺前台交互）
2. 投票帖（poll）
3. 用户主页标签页：主题 / 回复 / 收藏 / 徽章
4. 自定义表情与表情回复
5. 主题打赏/积分小费（已有积分与悬赏，可复用账本）
6. 页脚多列导航构建器（当前为单行链接）
7. 左侧板块图标栏（NodeSeek 桌面端）
8. PWA：manifest、离线页、安装提示

### P2：增长与智能化

1. 个性化推荐（基于标签/浏览/互动）
2. 相似主题与去重
3. AI 摘要、AI 审核辅助
4. Webhook / 开放 API Token
5. 多级菜单与权限可见性组合

## 3. 体验优化清单

- 英文复数处理：`1 Replies` → `1 reply`
- 后台英文翻译补齐 `admin.json`，移除 `/admin` 强制中文
- 帖子正文排版：代码块、引用、表格在移动端的横向滚动
- 键盘可达性：下拉菜单、灯箱、引用跳转
- 头像上传与默认头像生成
- 长帖阅读进度条与“回到顶部”（已有）
- 搜索结果高亮与筛选
- 列表骨架屏与空态插画
