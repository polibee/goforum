# 06 前端架构与设计系统

## 1. 设计原则

1. **服务端渲染优先**：首屏 HTML 完整可读，SEO 与低端设备友好。
2. **渐进增强**：表单在无 JS 时可提交；Alpine 只增强交互，不承担核心渲染。
3. **局部交互、局部数据**：页面级数据由服务端注入，点赞/关注/未读等变更走小接口。
4. **组件即模板**：Pines 组件本地化到 `web/templates/components/`，按项目 token 改写。
5. **无 SPA、无全局状态容器**：Alpine store 只保存跨组件的小状态。
6. **可度量**：性能预算、可访问性基线、错误可观测。

## 2. 资源管线

```
web/css/app.css ──Tailwind CLI──→ web/static/dist/app.<hash>.css
web/js/app.js ──esbuild──→ web/static/dist/app.<hash>.js
                                  │
                          manifest.json（hash 映射）
                                  │
                    Go embed.FS / 开发模式磁盘读取
```

### 2.1 构建

| 资源 | 工具 | 说明 |
|---|---|---|
| CSS | Tailwind CLI | 扫描 `web/templates/**/*.html`、`web/js/**/*.js`；生产 `--minify` |
| JS | esbuild | 打包 Alpine、插件与模块组件；`--minify --target=es2020` |
| 图片 | 构建期可选 | 站点 Logo/Favicon 生成多尺寸；用户上传走 media 模块 |
| 字体 | 本地托管 | 中文子集化可选；`font-display: swap` |

`Makefile` 目标：

```makefile
assets:        ## 构建 CSS/JS 并生成 manifest
dev:           ## tailwind --watch + esbuild --watch + go run
build:         ## assets + go build -trimpath -ldflags "-s -w"
test:          ## go test ./... + 模板渲染冒烟
```

### 2.2 缓存与版本

- 产物文件名带内容哈希，`Cache-Control: public, max-age=31536000, immutable`。
- `manifest.json` 在启动时加载；模板函数 `asset "app.css"` 解析为哈希路径。
- HTML 响应 `Cache-Control: no-cache`（游客页可单独配置短缓存 + ETag）。
- 开发模式直接读磁盘并禁用哈希，模板热重载。

### 2.3 CSP 与 Alpine

Alpine 默认使用 `new Function` 求值内联表达式，严格 CSP 下会被拦截。采用：

- 使用 **Alpine CSP build**（`@alpinejs/csp`），表达式仅允许调用已注册方法。
- 所有交互逻辑放入 `Alpine.data()` 工厂，模板中只写方法调用与简单属性访问。
- Pines 示例中的内联表达式改写到组件方法内，保持模板干净。
- 脚本通过 nonce 加载：`<script nonce="{{.CSPNonce}}" src="{{asset "app.js"}}" defer>`。
- 禁止内联 `onclick`、`javascript:` URL；自定义 CSS 由后台白名单校验。

### 3.2 布局与区块

`layouts/base.html` 定义骨架与可覆盖区块：

```go
{{define "base"}}
<!doctype html>
<html lang="{{.Site.Locale}}" class="{{.ThemeClass}}">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>{{.SEO.Title}}</title>
  {{template "seo_meta" .}}
  <link rel="stylesheet" href="{{asset "app.css"}}">
  {{block "head_extra" .}}{{end}}
</head>
<body class="bg-surface text-fg antialiased">
  {{template "skip_link" .}}
  {{block "body" .}}{{end}}
  {{template "toast" .}}
  <script nonce="{{.CSPNonce}}" src="{{asset "app.js"}}" defer></script>
  {{block "scripts" .}}{{end}}
</body>
</html>
{{end}}
```

页面定义 `content`，由 `shell` 注入：

```go
{{define "content"}}
  <div class="mx-auto max-w-7xl px-4 py-6">
    {{template "community/topic_list" .}}
  </div>
{{end}}
```

规则：

- 模板名全局唯一：模块模板统一前缀 `modules/<module>/<name>`。
- 组件参数使用结构体或 `dict`，禁止传裸 map 导致字段拼写错误。
- 页面 ViewModel 强类型；组件允许 `map[string]any` 但需在文档中列出键。
- 模板中禁止业务计算；复杂逻辑在 Service/ViewModel 完成。
- 所有用户内容输出使用 `html/template` 自动转义；已清洗 HTML 用 `template.HTML`，来源必须经过 bluemonday。

### 3.3 渲染器

- 生产：启动时解析全部模板到 `template.Template`，失败即启动失败。
- 开发：每次请求按依赖重新解析，支持热重载。
- 渲染顺序：布局 → 页面 → 组件；错误页使用最小依赖集合，数据库故障时仍可渲染。
- 统一注入：`Site`（站点设置）、`SEO`、`CurrentUser`、`CSRF`、`CSPNonce`、`AssetManifest`、`Flash`、`FeatureFlags`。

### 3.4 模板函数

| 函数 | 用途 |
|---|---|
| `asset "app.css"` | 带哈希的资源路径 |
| `csrf` | 当前 CSRF Token |
| `t "key"` / `t "key" arg` | 国际化文案 |
| `timeago` / `datetime` | 相对/绝对时间（用户时区） |
| `money` | 金额格式化（最小单位 + 币种） |
| `avatar` | 头像 URL + 占位图 |
| `url` | 路由生成，避免手写路径 |
| `json` | 安全嵌入 JSON（转义 `<`） |
| `dict` / `list` | 组件参数 |
| `hasPermission` | 当前用户权限判断（仅用于显隐，不替代服务端校验） |

## 4. Pines 集成

Pines 是 Alpine + Tailwind 的复制粘贴组件库。本仓库 `docs/pines/elements/` 已包含官方示例源码，接入策略：

1. 将所需组件源码复制到 `web/templates/components/`，重命名并替换为项目 token。
2. 依赖的 Alpine 插件统一在 `app.js` 注册：`focus`（弹层焦点）、`collapse`（折叠）、`intersect`（无限滚动）、`persist`（主题/草稿偏好）。
3. 组件行为改为 `Alpine.data()` 方法，兼容 CSP build。
4. 保留 Pines 的交互语义（键盘、外部点击关闭、过渡），视觉按设计系统重写。

## 5. Alpine 架构

### 5.1 全局 store

| store | 状态 | 方法 |
|---|---|---|
| `theme` | `mode`（light/dark/system） | `set`、`toggle`、`apply` |
| `toast` | 队列 | `push`、`dismiss`、`success/error` |
| `auth` | 当前用户、CSRF、权限集合 | `can`、`refresh` |
| `notifications` | 未读数、SSE 状态 | `connect`、`markRead`、`refresh` |
| `composer` | 草稿、脏标记、上传中 | `saveDraft`、`restore`、`submit` |
| `search` | 面板开关、查询、结果 | `open`、`close`、`query` |
| `checkout` | 当前订单、支付状态 | `poll`、`cancel` |

```js
Alpine.store('toast', {
  items: [],
  push(message, type = 'info') {
    const id = crypto.randomUUID()
    this.items.push({ id, message, type })
    setTimeout(() => this.dismiss(id), 4000)
  },
  dismiss(id) {
    this.items = this.items.filter(i => i.id !== id)
  }
})
```

### 5.2 组件工厂

```js
Alpine.data('topicList', () => ({
  items: [],
  cursor: null,
  loading: false,
  done: false,
  async init() {
    this.items = JSON.parse(this.$el.dataset.initial || '[]')
    this.cursor = this.$el.dataset.cursor || null
  },
  async loadMore() {
    if (this.loading || this.done) return
    this.loading = true
    try {
      const res = await gf.get('/api/v1/topics', { cursor: this.cursor })
      this.items.push(...res.data)
      this.cursor = res.meta.next_cursor
      this.done = !res.meta.has_next
    } catch (e) {
      gf.toast.error(e.message)
    } finally {
      this.loading = false
    }
  }
}))
```

### 5.3 数据请求封装

```js
window.gf = {
  async request(path, { method = 'GET', body, headers = {}, signal } = {}) {
    const res = await fetch(path, {
      method,
      headers: {
        'Accept': 'application/json',
        'Content-Type': 'application/json',
        'X-CSRF-Token': document.querySelector('meta[name=csrf-token]')?.content,
        ...headers
      },
      body: body ? JSON.stringify(body) : undefined,
      credentials: 'same-origin',
      signal
    })
    const payload = await res.json().catch(() => ({}))
    if (!res.ok) {
      if (res.status === 401) location.href = '/login?next=' + encodeURIComponent(location.pathname)
      if (res.status === 429) gf.toast.error('操作过于频繁，请稍后再试')
      throw new Error(payload?.error?.message || '请求失败')
    }
    return payload
  }
}
```

### 5.4 交互约定

- **乐观更新**：先改 UI，失败回滚并 toast；点赞、收藏、关注、已读必须如此。
- **防抖/节流**：搜索 250ms，滚动加载 200ms，窗口 resize 150ms。
- **并发控制**：同一操作进行中禁用按钮；`AbortController` 取消过期搜索。
- **事件命名**：`gf:<domain>:<action>`，如 `gf:topic:created`；禁止全局随意广播。
- **错误边界**：单个组件失败不影响页面其它区域；toast + 控制台上报。
- **无 JS 降级**：表单 `method=post` + 服务端重定向；点赞/收藏等增强功能不可用时隐藏或提示。

## 6. 设计系统

### 6.1 颜色 token

以 CSS 变量承载，Tailwind `theme.extend.colors` 引用变量，支持后台改色与暗色：

```css
:root {
  --gf-brand-50: #eef6ff;
  --gf-brand-500: #2563eb;
  --gf-brand-600: #1d4ed8;
  --gf-surface: #ffffff;
  --gf-surface-muted: #f8fafc;
  --gf-border: #e2e8f0;
  --gf-fg: #0f172a;
  --gf-fg-muted: #64748b;
  --gf-success: #16a34a;
  --gf-warning: #d97706;
  --gf-danger: #dc2626;
}
.dark {
  --gf-surface: #0b1220;
  --gf-surface-muted: #111a2e;
  --gf-border: #1e293b;
  --gf-fg: #e2e8f0;
  --gf-fg-muted: #94a3b8;
}
```

- 品牌色由后台设置生成 50–900 色阶；对比度必须满足 AA。
- 语义色只用于状态，不用于装饰。
- 暗色通过 `<html class="dark">`，首屏由服务端写入，避免闪烁。

### 6.2 排版与间距

| token | 值 | 用途 |
|---|---|---|
| 字体 | `system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` | 正文 |
| 等宽 | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | 代码 |
| 字号 | 12/13/14/16/18/20/24/30/36 | 辅助/正文/标题 |
| 行高 | 1.5（正文）、1.25（标题） | — |
| 圆角 | 6/8/12/16/full | 按钮/卡片/弹层 |
| 间距 | 4 的倍数 | 统一节奏 |
| 容器 | 720（阅读）/1024/1280/1440 | 页面宽度 |

### 6.3 组件层

```css
@layer components {
  .gf-btn { @apply inline-flex items-center gap-2 rounded-md px-3.5 py-2 text-sm font-medium transition; }
  .gf-btn-primary { @apply bg-brand-600 text-white hover:bg-brand-700 disabled:opacity-50; }
  .gf-btn-ghost { @apply text-fg-muted hover:bg-surface-muted hover:text-fg; }
  .gf-input { @apply w-full rounded-md border border-border bg-surface px-3 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-brand-500; }

```

- 正文使用 `@tailwindcss/typography`，代码块、引用、表格统一风格。
- 所有交互元素有 `focus-visible` 环；禁用态降低不透明度但不改变布局。
- 密度切换（紧凑/舒适）通过 `data-density` 调整行高与内边距。

### 6.4 暗色与主题

- 支持 `light / dark / system` 三态，存 `localStorage` 与用户设置。
- 服务端根据用户偏好输出初始 class，避免 FOUC。
- 图片在暗色下降低亮度（可选）；代码高亮使用双主题。
- 后台可设置默认模式与是否允许用户切换。

## 7. 响应式与移动端

| 断点 | 宽度 | 主要变化 |
|---|---|---|
| `sm` | 640 | 单列内容、卡片化列表 |
| `md` | 768 | 显示侧边栏 |
| `lg` | 1024 | 完整三栏 |
| `xl` | 1280 | 更宽容器 |

移动端差异：

- 顶部导航折叠为 Slide-over；可选底部标签栏（首页/板块/搜索/通知/我的）。
- 主题列表从表格改为卡片，显示标题、作者、回复数、最后回复。
- 发帖按钮为悬浮 FAB 或底部固定按钮。
- 编辑器全屏；图片粘贴与相机上传。
- 触控目标 ≥ 44×44；避免 hover-only 操作。

## 8. 可访问性

- 每页一个 `<h1>`；标题层级连续。
- 跳转链接（跳到主内容）；地标 `header/nav/main/footer`。
- 弹层：焦点陷阱、ESC 关闭、关闭后焦点回到触发元素、`aria-modal`。
- Toast：`role="status"` + `aria-live="polite"`；错误用 `assertive`。
- 表单：显式 `<label>`、错误与字段 `aria-describedby` 关联、`aria-invalid`。
- 图标按钮必须有 `aria-label`；装饰图标 `aria-hidden`。
- 支持 `prefers-reduced-motion`，关闭非必要动画。
- 颜色对比度 ≥ 4.5:1（正文）、3:1（大文本/边框）。

## 9. 性能预算

| 指标 | 预算 |
|---|---|
| 首屏 CSS | ≤ 40 KB（gzip） |
| 首屏 JS | ≤ 45 KB（gzip） |
| 字体 | ≤ 2 个文件，≤ 120 KB |
| 首屏请求数 | ≤ 12 |
| LCP | ≤ 2.5 s（4G） |
| CLS | ≤ 0.1 |
| INP | ≤ 200 ms |

手段：

- 图片 `loading="lazy"`、`decoding="async"`、显式宽高、`srcset`。
- 非首屏组件按需加载（动态 `import()`）。
- 列表分页/无限滚动，避免一次渲染上千节点。
- 模板片段缓存（游客页）；避免重复查询。
- 长列表使用 `content-visibility: auto`。

## 10. 状态与文案

每个数据区域必须实现四种状态：

| 状态 | 表现 |
|---|---|
| 加载 | 骨架屏，尺寸与真实内容一致 |
| 空 | 插图/图标 + 一句说明 + 主行动按钮 |
| 错误 | 原因 + 重试按钮 + 请求 ID |
| 无权限 | 说明 + 登录/申请入口（不泄露资源存在性） |

文案规范：动作按钮用动词（发布、保存、删除）；危险操作明确后果；错误文案不暴露内部实现。

## 11. 国际化与格式化

- 文案键：`<module>.<page>.<element>`，默认 `zh-CN`，预留 `en-US`。
- 时间：服务端输出 ISO，前端用 `Intl.RelativeTimeFormat`/`Intl.DateTimeFormat`。
- 金钱：`Intl.NumberFormat(locale, { style: 'currency', currency })`，金额来自最小单位。
- 数字：千分位；积分大数用 `1.2k` 简写（可切换完整值）。

## 13. 前端测试

- 模板冒烟：每个页面用固定 ViewModel 渲染，断言关键区块与 SEO 标签存在。
- 组件测试：`Alpine.data` 纯逻辑抽取为函数，单测覆盖加载/失败/回滚。
- E2E（Playwright 可选）：注册→发帖→回复→点赞→通知→举报→后台审核→支付。
- 可访问性：axe 扫描关键页面；键盘走查。
- 视觉回归：暗色/移动端截图对比（可选）。

## 14. 验收标准
